# Module Template
This is a template that you can use to build your own custom modules. It has all available hooks already connected, but has no logic. It is already configured
to load in the router via the main.go file.

# References
For more guidance on how to build custom router modules, see:

* Standard hooks: https://cosmo-docs.wundergraph.com/router/custom-modules
* Cosmo Streams hooks: https://cosmo-docs.wundergraph.com/router/cosmo-streams/custom-modules
